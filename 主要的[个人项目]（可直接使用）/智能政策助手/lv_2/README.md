### 前言

也许我根本不适合做决策和指挥的人（而且我也不善于沟通，也没法将脑内的想法表达出来（如果是我的话，我恐怕会一点一点试，然后慢慢的就能打起来效果了））

报名了一个AI政策智能体的赛项
暂定是复赛，赛项内容要求，有系统架构，有技术选型，有PPT实现文档，实现的效果和过程，流畅性，创新和显示效果，根据实现效果进行打分，报名截止时间还剩17天

临时找了两个人组队
一开始我的想法是试试他们的能力，要求他们先做出来一个小型的demo，能够输入政策问题，输出和回复，在这基础上再考虑继续（也有报别的组报了同样的内容）（但他们似乎没有什么具体的想法，我已经会了就是了）

因此我给了他们一个实现方向，用python代码调取API模型做到内容输出

但进行了差不多两次讨论，都是在最基本的层面上绕圈子，关于怎么实现的问题

能够输入问题，输出政策
用智谱大模型的API调用，最后输出结果就可以实现
比赛裁判的评分标准是什么？
我之前做的那个，Ai vtube也差不多实现了类似的效果，干脆在这个基础上直接写就行（但我个人认为那种效果最多只能拿到四五十分）
像Cherry studio那样，支持知识库和联网功能，可以根据联网搜索结果和知识库内容输出结果
那为什么不直接用Cherry studio进行开发呢？
（估计裁判是形而上的，在主要功能实现后，估计60分，之后的内容就是在创意性和显示效果精准度上的进行评分）
既然如此，像gork 4那样，输入一个问题，先进行思考，任务规划，联网搜索，关键词提取，知识库整合，政策内容的结构化效果输出，并附带上每个政策的出处（如果是像这样的话，那么至少能拿到80到九十分以上呢）
为什么不拿现成的已经完成的模型项目，在那基础上改进，直接拿去用得了
裁判看的也是PPT和演示效果，那么干脆光做前端的功能按钮，不做功能实现，裁判一看这么多功能，说不定也可以高分

最后想了很长时间
要么就是找现成的模型框架改进
要么就把每个功能从头搭起来，进而实现系统架构（我负责主要功能的实现，打算让他们试试数据的获取和前端的效果）

问了问他们什么想法？最后他们表示，要不干脆退赛吧

因此我在想会不会是我没有清晰的方向和一个强烈的信标，才导致的这个原因，像是你们只要跟着我走，相信我就没问题这种人格魅力和清晰的头脑
