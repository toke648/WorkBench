# Personal Chronicle（个人编年备份）

## 目标
按年份/阶段备份你的写作、日志、博客摘录、代码快照与思想草稿。每年做一次整理（Archive），并保留关键文稿与快照。

## 目录建议
- 00-README.md
- archives/
  - 2023/
  - 2024/
  - 2025/
- drafts/
- blog-backups/
- metadata/  # 列表化每年重要事件与关键词

## 使用建议
- 每次大改（比如一篇长文完成）都做一次 commit 并写清改动日志。
- 把研究宣言、长文稿、重要对话（你愿意保留的）都分类存放。
